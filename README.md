✈️ Airline Reservation System (Java GUI)

A simple Java Swing-based application that allows users to book airline tickets through a graphical interface. This project is designed as a basic college mini project.

-> Features
- Enter passenger name
- Select flight
- Enter seat number
- Book ticket
- View booking details
- Reset form
- Exit application

-> Technologies
- Java
- Java Swing

-> How to Run

 ->Using Eclipse
1. Open Eclipse
2. Import project
3. Run `Main.java` as Java Application

-> Using Terminal
cd AirlineReservationSystemGUI
cd src
javac -d ../out module-info.java airline/*.java
java --module-path ../out --module AirlineReservationSystemGUI/airline.Main

 ->Output
The application opens a window where users can book and view airline ticket details.
